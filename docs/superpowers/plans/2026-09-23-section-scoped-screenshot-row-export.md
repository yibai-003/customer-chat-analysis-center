# 工单 6：单板块截图行导出实施计划

## 目标

- 导出入口只接受任务 ID，板块和配置版本完全取自任务绑定。
- 用版本化导出契约定义目标行、字段来源、表头顺序和序列化格式。
- 接待质检只回填截图记录所在原始行，不新增行、不使用预留行。
- 在写文件前完成多问题结构和 Excel 单元格长度校验。
- 保留原工作簿的工作表、行、图片、样式、公式和无关单元格。

## 实施

1. 扩展 `SectionConfigVersion.exportSettings`：
   - `rowMode`: `records` 或 `screenshot_records`
   - `outputColumns`: 增加字段来源和格式定义，同时兼容历史版本的旧结构
2. 接待质检当前配置增加版本化导出列：
   - 平台、会话 ID
   - 问题、维度、扣分、合计扣分、是否 D 级
   - 聊天原文、证据说明、判定理由、优化建议
   - 接待流程质检结果、是否待人工复核、会话开始时间、对话轮数
3. 新增不可变迁移，为接待质检创建带新导出契约的当前已发布版本。
4. 重构导出服务：
   - 只读取任务绑定版本
   - 按版本列顺序原位复用或末尾追加
   - 从任务、记录和结构化质检结果生成值
   - 校验问题/维度/扣分对齐及 32767 字符上限
5. 配置发布校验：
   - 接待问题名称和维度禁止英文逗号
   - 接待导出契约必须包含合法的结构化格式和截图行模式
6. 更新 API、客户端和调用方，删除多板块导出参数。
7. 增加真实 XLSX 回读测试，覆盖多问题聚合、无问题、预留行、列复用/追加、图片锚点、行数、样式、公式及错误阻断。
