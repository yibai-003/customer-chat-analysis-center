# 百炼免费模型池动态同步设计

**日期：** 2026-10-10

**状态：** 已审阅，实施计划就绪

**关联工单：** [GitHub Issue #16](https://github.com/yibai-003/customer-chat-analysis-center/issues/16)

**设计类型：** 架构级跨本机采集器、服务端模型池与管理工作台变更

## 1. 目标

用当前 Windows 运行主机上已登录的阿里云百炼 CLI，更新应用中的免费模型池。每次同步按关联百炼账户的当前免费额度、模型能力和在线状态筛选；已过期、耗尽、下线或不适用的托管成员退出活动池。两个现有付费默认模型保持原配置，并在界面列表中置底，继续作为最终兜底。

第一阶段使用主机命令触发并预览；不让容器读取主机的 Bailian CLI 登录配置，不建设网页直连 CLI 的本机代理。

## 2. 领域词汇

| 术语 | 定义 |
| --- | --- |
| 百炼免费额度快照 | Windows 主机 CLI 查询到的某个百炼账户在某一时刻的模型额度和目录元数据；快照不含认证凭据。 |
| 托管免费池成员 | 由同步流程识别并维护的免费模型配置。它与手工配置成员、付费默认成员分开管理。 |
| 预览 | 服务端根据完整快照与当前数据库状态计算待新增、更新、停用差异，不写入模型池。 |
| 应用 | 在确认预览仍有效后，将完整同步差异作为一个事务写入数据库。 |
| 手动剔除 | 管理员主动移出池的状态；同步不得自动恢复该状态。 |

额度快照里的一个具体模型 ID（包括日期后缀版本）是额度原子单位。相同 ID 只对应一个用途，防止把同一份账户额度同时计入文本和视觉池。若模型同时支持两种用途，首版按额度清单类型决定其唯一用途；后续如需一份额度跨用途共享，须另行设计共享额度账本。

## 3. 方案与架构

### 3.1 选定方案

采用“Windows 主机采集器 + 服务端预览/原子应用接口”：

1. PowerShell 主机脚本通过本机 `bl` 进程读取 `bl usage free --all --output json` 和百炼模型目录。
2. 脚本校验响应可解析、字段合法、模型 ID 唯一、目录覆盖和账户额度记录完整；无法证明快照完整时直接失败，不上传部分数据。采集器只采集适用的文本/视觉额度项，并为这些精确模型 ID 拉取完整版本详情。
3. 脚本提示项目管理员登录信息，以 HTTPS 或明确允许的回环/本机地址登录项目；密码与 Cookie 仅存于进程内存，不写入命令行参数、环境变量、文件或日志。
4. 脚本要求管理员明确确认：当前 Bailian CLI 登录账户与选定的应用百炼服务商 API Key 属于同一个百炼账户。百炼 CLI 和应用当前接口没有可安全比对的共同账号标识，因此此项是操作者确认，系统不得宣称已机器验证。随后脚本将不含凭据的快照提交至项目管理接口，获取服务端生成的预览变更清单。
5. 管理员确认后，脚本使用短期预览 ID 应用变更；服务端复核预览 TTL、快照摘要和当前相关池状态，并在单个 SQLite 事务中写入。
6. 服务端使用明确选中的、已启用的百炼服务商 ID 关联已有提供方凭据。没有配置、被停用或存在多个无法确定的候选提供方时，拒绝预览/应用，不猜选。

后续管理界面如要一键发起同一同步，另需设计受控的主机代理；浏览器不能直接访问 Windows CLI 凭据。服务端候选筛选、差异计算和事务应用模块可以保持不变并复用。

不采用逐成员 CRUD：这会导致部分失败时的半更新。也不把 CLI 登录配置挂入 Docker：这会扩大登录凭据的可访问面并耦合宿主机目录。

### 3.2 数据流

```text
Windows Bailian CLI
  ├─ 免费额度：model / type / remaining / total / expires / autoStop
  └─ 模型目录：model / provider / capabilities / modalities / offline / features
          ↓ 纯模型元数据快照（不含 CLI 凭据和模型 API Key）
主机脚本 → 项目登录会话 → 预览 → 管理员确认 → 原子应用
                                     ↓
                       服务端池同步模块 → SQLite + 安全审计
```

## 4. 候选筛选和能力标准

### 4.1 免费额度

一个模型 ID 必须同时出现在额度快照与百炼模型目录中。匹配使用精确模型 ID，不能只按模型系列名合并基础模型与快照版本。

当前 CLI 免费额度记录字段包括 `model`、`type`、`remaining`、`total`、`expires` 和 `autoStop`。纳入候选的必要条件：

- `remaining` 与 `total` 均为非负安全整数，且 `remaining > 0`、`total > 0`；
- `expires` 是可解析的日期且尚未到期；对只含日期的值按百炼账户所在中国时区解释，配置当天到期时仍可用至当日结束；
- `autoStop === true`，避免剩余额度耗尽后转为按量付费；
- 模型目录对该精确模型版本有唯一详情记录，标记 `offline=true` 的版本排除；目录中未来下线时间如早于额度到期时间，则池内有效截止时间取较早者；
- 百炼额度源中的模型 ID 在目录中恰好匹配一个具体版本；歧义或缺失时整份快照不允许应用。

额外要求 `autoStop=true` 是项目防止意外付费的本地保护，不会替用户在云控制台打开开关。若账户未开启该选项，脚本在预览中明确列出为“因付费风险排除”，不会自动改变云账户设置。剩余额度还必须高于模型池当前的 95% 安全线；处于安全线内但大于零的额度不会进入候选，并显示“低于本地安全线”。

### 4.2 目录能力

目录至少能识别实时对话兼容能力（OpenAI-compatible Chat Completions）和文本响应。使用官方能力与模态元数据，不按名称猜能力：

| 额度 `type` | 应用用途 | 目录要求 |
| --- | --- | --- |
| `Text` | `text` | `TG`，文本输入，文本输出，并在目录中声明结构化输出支持。 |
| `Vision` | `vision` | `VU`，图片输入，文本输出，并在目录中声明结构化输出支持。 |
| `Multimodal` | `vision` | `VU` 或 `Multimodal-Omni`，图片输入、文本输出，并在目录中声明结构化输出支持。 |
| Audio、Embedding、空/未知类型 | 排除 | 不属于当前项目模型池用途。 |

CLI 对一个额度模型 ID 使用详情查询时，必须得到包含该 ID 的唯一版本项；离线版本由 `offline=true` 排除，目录字段缺失、版本重复或结构化输出信息不足时作为排除原因显示，不能静默降级成按名称匹配。采集器一次快照最多接受 500 条额度记录与 500 条模型版本详情；超过上限时停止并报告，避免不受控内存和请求规模。

## 5. 模型池状态和更新行为

### 5.1 托管成员标识

沿用现有 `preset_key`/`preset_version` 托管来源标记，以 `bailian-free-pool` 作为动态同步标识；已经由静态千问预设创建的 `qianwen-free-pool` 成员作为受管旧标识迁移，保留 ID、额度用量、验证、剔除和历史事件。版本值记录同步算法版本而非账号密钥、目录快照原文或 CLI 配置。人工成员和 `is_purpose_default=true` 的付费成员永远不属于托管集合。

### 5.2 新增与更新

- 新成员复用指定 provider ID 和模型目录显示名，写入额度总量、剩余额度换算后的已用量、有效截止时间、用途、托管标识和确定性优先级。首批新成员按有效截止时间升序、模型 ID 升序排列，并分配到当前受管免费成员最大优先级之后的优先级；后续同步不改写已有成员的管理员优先级。
- 新成员保持业务配置启用，但 `pool_enabled=false`，且没有已通过的能力验证；因此在验证前不会进入路由。管理者必须使用已有能力验证动作，通过后显式启用。
- 已有托管成员更新总额度、云端剩余额度换算的使用量、有效截止时间及可安全更新的目录信息；云端剩余量重新大于本地安全线时清除当前额度阻断标记。保留有效能力验证结果、冷却/失败诊断、模型使用事件、管理员编辑的非托管字段。
- 若百炼返回剩余量比应用运行期间本地推算值高，不将其钳制为更低；百炼账户快照是该免费模型云端额度的权威值。
- 不改动两个付费默认模型、供应商 API Key、每日/月度付费预算和分析历史。

### 5.3 停用与人工操作

- 托管成员在完整快照中缺失、额度耗尽、过期、目录下线或能力不符，应用后设置 `pool_enabled=false` 并标记原因；保留行、外键引用与历史事件，不删除。
- 手动剔除的成员不因其再次出现于账户快照而自动恢复 `pool_enabled`；同步只刷新云端额度和目录元数据，并保留管理员剔除状态/理由。
- 非托管免费成员不由本同步清理。
- 两个付费默认兜底模型保持启用配置和默认身份；全局候选排序、池列表和前端展示均让其处于免费成员之后/底部。此排序由服务端策略保证，而不是只用 UI 排序。

### 5.4 同步幂等

同一 provider、用途、精确模型 ID 在数据库内最多匹配并维护一条托管成员。发现多条历史重复、模型 ID 对应用途冲突或同一模型被另一个手工配置占用时，预览失败并要求管理员处理，不自动合并或接管手工配置。

## 6. 预览、应用与错误保护

- CLI 退出码非零、输出截断/格式错误、额度或目录分页不全、超时、适用额度模型目录匹配缺失/重复、额度范围字段无效，或操作者没有明确确认 CLI 账户与应用 provider 属于同一百炼账户：不允许生成可应用预览。
- 若 CLI 成功返回结构完整且确认为零候选的快照，仍可生成预览；预览必须明确显示“将停用全部受管免费模型”和成员数量。应用前要求操作者键入 `STOP ALL MANAGED FREE MODELS` 二次确认。无效或无法解析的空内容不视为零候选快照。
- 规范快照最多含 500 条额度记录和 500 条目录版本；超过容量返回安全错误。每次预览明确列出新增、更新、停用和被排除的具体数目及模型 ID，不使用未定义的“变化过大”比例阈值。
- 预览结果包含新增、字段更新、拟停用、被排除原因和付费默认保护摘要；不展示或记录凭据。
- 当前 LAN 部署是单进程 SQLite。服务端在进程内保存最多 20 个随机预览 ID，每个 ID 5 分钟有效、只允许对应预览操作人消费一次；过期项定期清理。进程重启会让未应用预览失效，脚本须重新生成。应用时复核当前托管池指纹、provider 启用状态和用户权限，防止预览后发生修改。
- 事务写入任一失败则全部回滚。登录过期/权限不足、provider 不明确、预览失效、快照格式校验失败时返回可理解错误且零数据库修改。
- 每次预览/应用审计记录操作人、provider ID、结果与数量摘要，不记录 CLI 原始输出、Cookie、密码、API Key、完整账户标识或包含敏感字段的原始快照。

## 7. 用量验证和费用边界

同步过程只读取额度和模型目录，不调用推理 API。现有能力验证会发送文本、JSON 以及视觉探测请求，视觉验证确实包含一张内嵌测试图片，因此可能扣减百炼免费额度。

新成员在通过该现有验证且由管理员启用前不可路由。验证按现有人工操作显式发起；界面应提示其会实际调用模型。同步不能自动验证、批量验证或开启云端免费额度开关。

CLI `autoStop=true` 是目录快照中的用户账户保护状态。本项目的配额仍使用本地运行账本与 95% 安全线，两者同时生效；本地池必须预留安全线，不能因为云端剩余额度为正就忽略本地账本。

## 8. 模块接口与职责

### 8.1 主机采集器

输入：项目基础 URL、管理员交互式登录凭据、可选 provider ID（若无法唯一推断）。

主要步骤：执行白名单 `bl` 子命令；对 CLI JSON 进行严格解析；合并额度与目录；生成去敏快照；登录项目；请求预览；以人类可读形式展示差异；交互式确认后请求应用。HTTP 请求限制为本机/HTTPS，设置超时和响应体上限。标准输出仅报告模型数与变更摘要；调试错误必须先脱敏。

### 8.2 服务端同步模块

单一外部接口概念：接收已规范化快照并预览；凭短期 previewId 确认应用。模块负责 Schema 校验、模型与额度策略、差异计划、数据库事务、审计安全摘要。路由只做 `config:manage` 权限、输入和状态码适配。测试可注入 CLI 数据快照与时钟，不需真实阿里云账号。

### 8.3 界面

本期移除静态预设误导，将“免费池安装/更新”区域改为本机同步命令与状态指引；能明确展示付费兜底模型固定置底。UI 不直接访问 CLI、百炼控制面或数据库。后续一键代理仅复用服务端同步模块。

## 9. 数据迁移与恢复

设计目标是复用当前模型池已有额度、托管来源和剔除字段；如实现发现不足，必须新增有序迁移、更新迁移锁并覆盖旧数据和重复执行，不得修改已发布迁移。不能直接替换运行环境数据库或清除模型使用历史。运行数据库变更前遵守数据库备份和恢复指南，且只对用户明确授权的测试 LAN 数据执行。

## 10. 测试和验收

### 单元测试

- CLI 原始 JSON 解析、范围与额度字段校验、日期边界/中国时区、精确快照版本匹配。
- `Text`、`Vision`、`Multimodal` 和排除类型的用途映射；结构化 JSON、文本/图片能力判定。
- 额度为零、autoStop 关闭、目录离线、缺失/重复、未知字段和空快照的安全失败策略。
- 新增成员默认未入池；云端剩余额度变化更新；手动剔除状态、失败/冷却/能力和历史事件保留。
- 非托管成员与付费默认成员不变，候选/界面排序确保付费默认最后。
- 幂等、重复历史拒绝、过期 previewId 与池指纹不匹配拒绝应用。

### 路由/集成测试

- 未登录、缺少 `config:manage`、不存在或停用 provider 均被拒绝。
- 无效快照或写入失败不落任何变更；有效快照完整原子应用。
- 同步审计不含测试中构造的密码、Cookie、API Key 或 CLI 原始 JSON 哨兵值。
- 同步流程不请求模型 transport；验证模型的网络调用仍只发生在显式验证流程。

### 项目命令

焦点测试通过后按项目约定运行：

```powershell
npm test
npm run typecheck
npm run lint
npm run build
npm run db:check
npm run smoke
npm run check:installation
```

另需对脚本做 Windows PowerShell 本机运行验证和测试 LAN 隔离验证。除用户明确批准外，不对正式生产版或真实模型池做 apply；测试环境应用须先确认数据目录是 LAN 测试版本，并在变更前有可恢复备份。

## 11. 范围外事项

- 网页一键调用主机 CLI 所需的驻留代理。
- 云端免费额度“用完即停”设置的自动开启/关闭。
- 自动运行模型推理能力验证或代表管理员开启新候选。
- 音频、语音、向量、视频/图像生成等当前客服分析流程不消费的能力池。
- 修改现有付费默认模型或其供应商凭据。
- 自动调度定时同步。
