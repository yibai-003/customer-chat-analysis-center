# 板块知识库与知识路径解析设计

日期：2026-09-09

## 目标

为每个解析板块提供独立知识库。知识库支持 Excel 批量导入和网页编辑，并通过本地检索缩小候选范围。字段解析链只调用一次文本模型选择完整知识条目，后续结果字段直接从该条目中取值。

该设计需要满足：

- 不同板块可以使用完全不同的知识表头。
- 一个板块的知识不参与其他板块检索。
- Excel 重复导入执行增量更新，不自动删除旧知识。
- 分类模型只能选择已召回的知识条目，不能自创分类。
- 多个结果字段必须来自同一条知识快照。
- 内部匹配字段不写入导出的 Excel。
- 历史任务不受后续知识修改或重新导入影响。

## 已验证输入

`退货原因汇总.xlsx` 包含一个工作表，表头为：

- 一级原因
- 二级原因
- 三级原因

文件共有 388 条知识路径：

- 14 个一级原因。
- 251 条一级、二级组合路径。
- 143 条包含三级原因。
- 245 条不包含三级原因。
- 没有重复完整路径。
- 3 条知识只包含一级原因。

该文件可以直接导入，不要求增加商品范围。

## 核心概念

### 板块知识库

知识库归属于一个解析板块。一个板块可以保留多个导入文件记录，但检索范围只包含该板块中已启用知识库的已启用条目。

### 动态知识结构

系统不固定一级、二级、三级字段。首次导入 Excel 时读取全部表头，并让用户设置每列用途：

- `result`：可供解析字段提取的结果列。
- `search`：参与全文检索的普通内容。
- `keyword`：高权重检索关键词。
- `description`：判定说明。
- `positive_example`：正向案例。
- `negative_example`：反向案例。
- `metadata`：保存但不参与默认检索的附加信息。

同一列可以是结果列并参与检索。退货分析中的一级原因、二级原因、三级原因均配置为结果列和检索列。

### 知识条目

Excel 每个非空数据行对应一条知识条目。条目保存：

- 动态列值 JSON。
- 用于去重的路径键。
- 规范化检索文本。
- 来源文件和来源行号。
- 启用状态。
- 创建时间和更新时间。

路径键由所有配置为 `result` 的列按列顺序组合生成。空值参与位置占位，避免不同层级路径错误合并。

## Excel 导入

### 首次导入

1. 选择所属板块和 Excel 文件。
2. 读取工作表、表头和数据行。
3. 为每个表头配置列用途。
4. 至少选择一个结果列。
5. 生成导入预览。
6. 用户确认后以事务方式写入知识条目并更新 FTS 索引。

### 重复导入

系统复用已保存的列映射。按路径键执行：

- 路径不存在：新增。
- 路径存在且内容变化：更新。
- 路径存在且内容相同：跳过。
- 旧知识未出现在本次文件：继续保留。

导入预览显示新增、更新、跳过、重复和异常数量。

### 校验规则

- 空白行自动跳过。
- 表头为空或重复时阻止导入。
- 没有结果列时阻止导入。
- 同一文件内重复路径合并并在预览中提示。
- 动态结构不强制二级或三级存在。
- 对退货分析等层级知识，可以在列映射中开启“后级非空时前级必须非空”的层级校验。
- 导入失败时事务回滚，保留原知识和原索引。

## 检索流程

### 查询输入

知识匹配字段使用其依赖字段构建查询，包括：

- 截图解析结果。
- Excel 辅助字段。
- 其他已完成的 AI 字段。

字段配置决定哪些依赖进入检索文本。

### 本地候选检索

1. 限制到当前板块和指定知识库。
2. 排除停用知识库和停用条目。
3. 使用 FTS5 trigram 检索中文文本。
4. 对关键词列、完整结果值命中和连续短语命中提高权重。
5. 使用普通包含匹配补充短文本和特殊符号候选。
6. 合并去重并返回默认前 15 条候选。

候选数量可在字段配置中调整，建议范围为 5 至 30。

### 模型最终匹配

文本模型收到：

- 字段级提示词。
- 依赖字段内容。
- 候选条目的稳定 ID。
- 候选条目的结果列、判定说明、关键词和案例。

模型只能返回一个候选知识条目 ID 或空值。服务端验证 ID 必须存在于本次候选集合，验证通过后保存知识匹配快照。

无法可靠匹配时返回空值，记录标记为需要复核。模型不得创建新分类或改写知识列值。

## 字段解析类型

`analysis_fields` 增加以下配置：

- `execution_type`
  - `ai`：现有 AI 字段解析。
  - `knowledge_match`：检索候选并调用文本模型选择知识条目。
  - `knowledge_extract`：从知识匹配快照直接提取列值。
- `export_enabled`
- `knowledge_base_id`
- `candidate_limit`
- `match_field_key`
- `knowledge_column`

### AI 解析字段

保持现有图片开关、提示词、依赖字段和模型用途选择。

### 知识库匹配字段

- 默认作为内部字段。
- 不要求绑定 Excel 输出列。
- 依赖截图解析和辅助字段。
- 调用一次文本模型选择完整知识条目。
- 结果保存知识条目 ID 和完整快照。

### 知识结果提取字段

- 不调用 AI。
- 依赖知识库匹配字段。
- 根据 `knowledge_column` 从匹配快照取值。
- 对应列不存在或为空时输出空字符串。
- 可绑定 Excel 输出列。

### 模型选择

字段链执行时按字段类型单独选择执行器和模型，不能继续为整条字段链共用一个模型：

- 开启图片解析的 `ai` 字段使用截图提取模型。
- 不包含图片的 `ai` 字段使用字段分析模型。
- `knowledge_match` 字段使用字段分析模型。
- `knowledge_extract` 字段不获取模型、不发起接口请求。

## 退货分析字段链

退货分析推荐配置：

1. `截图解析`
   - 类型：`ai`
   - 图片解析：开启
   - 模型：截图提取模型

2. `原因路径匹配`
   - 类型：`knowledge_match`
   - 内部字段：是
   - 导出：否
   - 依赖：截图解析和所需 Excel 辅助字段
   - 模型：字段分析模型

3. `一级选项`
   - 类型：`knowledge_extract`
   - 匹配来源：原因路径匹配
   - 知识列：一级选项或导入文件映射后的一级原因列

4. `二级选项`
   - 类型：`knowledge_extract`
   - 匹配来源：原因路径匹配
   - 知识列：二级选项或导入文件映射后的二级原因列

5. `三级选项`
   - 类型：`knowledge_extract`
   - 匹配来源：原因路径匹配
   - 知识列：三级选项或导入文件映射后的三级原因列

一级、二级、三级始终来自同一知识条目。知识条目中没有二级或三级时，对应输出留空。

## 提示词调整

### 截图解析

继续使用独立的截图提取提示词，只输出客观事实、证据、关键词、责任线索和信息充分度，不直接匹配完整分类路径。

### 原因路径匹配

使用原一级原因提示词中的证据优先级、责任边界和特殊业务规则，但输出目标改为：

- 只能从本次候选条目中选择。
- 只返回一个候选条目 ID。
- 无可靠匹配时返回空值。
- 不得改写候选分类。

原二级、三级提示词中的具体边界规则逐步迁移到知识条目的判定说明、关键词、正向案例和反向案例中。

### 结果提取字段

一级、二级、三级等结果提取字段不再配置 AI 提示词。配置界面仅显示匹配来源和知识列。

## 管理界面

每个板块增加“知识库”入口，并提供独立管理页面。

### 内容管理

- 显示知识库文件名称、动态列数量、条目数量、状态和更新时间。
- 支持导入、重新导入、启用、停用和删除。
- 删除使用现有像素风格确认弹窗。

### 知识条目

- 根据动态列结构生成列表。
- 支持搜索、状态筛选、新增、编辑、删除和批量启停。
- 编辑器显示结果字段以及可选的判定说明、关键词、正向案例和反向案例。

### 检索测试

- 输入模拟截图解析结果和辅助字段。
- 显示候选排名、命中内容、相关度和条目状态。
- 检索测试不调用分类模型，只验证本地召回结果。

### 字段配置

字段卡片增加解析方式选择。界面按解析方式显示对应控件：

- AI 解析：提示词、图片解析、依赖字段。
- 知识库匹配：知识库、提示词、依赖字段、候选数量、是否导出。
- 知识结果提取：匹配来源、知识条目列、目标 Excel 字段。

## 错误与复核

- 知识库未配置或已停用：匹配字段失败并显示明确错误。
- 本地未召回候选：匹配字段结果为空并标记需要复核。
- 模型返回非候选 ID：匹配结果无效并标记需要复核。
- 匹配字段为空：依赖它的结果提取字段输出空值，不发起模型调用。
- 知识列被删除或改名：字段配置标记失效，阻止批量解析前启动检查。
- 历史匹配条目被停用或删除：历史快照和导出结果继续有效。

## 测试范围

- 动态表头导入和列用途映射。
- 增量新增、更新、跳过和旧知识保留。
- 文件内重复路径合并。
- 中文 trigram 检索和包含匹配兜底。
- 板块隔离与启用状态过滤。
- 模型只能选择候选 ID。
- 匹配失败后的复核状态。
- 知识提取字段不调用模型。
- 空二级、空三级保持空值。
- 内部字段不导出 Excel。
- 多个提取字段使用同一知识快照。
- 知识编辑后历史任务结果不变化。
- Excel 导入失败事务回滚。

## 非目标

第一阶段不包含：

- Embedding 模型和向量数据库。
- 跨板块知识检索。
- Word、PDF 等非 Excel 文件自动拆分。
- 多用户权限和知识审核流程。
- 自动删除本次 Excel 未出现的旧知识。
