# 未成交分析板块优化设计

**日期：** 2026-09-15

## 目标

将未成交分析从“一个视觉字段加四个独立文本字段”优化为低调用、可统计、可维护的统一归因流程。

## 已确认决策

- 截图内容总结只负责客观还原聊天事实，调用一次视觉模型。
- 新增不导出的内部字段“未成交归因”，调用一次文本模型。
- 统一归因输出 1-2 个客户原因、1-2 个客服原因、1-2 个客户需求类型，并保留具体需求、证据和置信度。
- 客户原因和客服原因分别使用独立知识库；统一归因直接选择知识库中的标准名称，不为每个字段重复调用匹配模型。
- 客户产品需求对外继续导出具体需求，内部保留需求类型。
- 话术逻辑优化建议默认使用本地规则模板，必要时再调用 AI 润色。
- 没有明确证据时使用“待复核”或“无明确未成交依据”，不强行归类。
- 多个结果在 Excel 单元格内使用换行分隔。
- 历史结果不自动重算，新记录使用新流程。

## 目标数据流

```text
截图内容总结（vision）
        ↓
未成交归因（text，一次调用）
        ↓
客户原因 / 客服原因 / 客户产品需求（本地提取）
        ↓
话术逻辑优化建议（本地规则，按需 AI）
```

## 知识库

创建两个独立知识库：

1. 客户未成交原因库：原因名称、原因定义、适用条件、排除条件、示例表达。
2. 客服促单问题库：问题名称、问题定义、识别条件、排除条件、改进方向、示例话术。

知识库初始化使用已确认的客户原因、客服原因分类。自动归因不得自动创建新原因词条；库外或证据不足的结果进入待复核。

## 兼容性

- 保留现有导出字段名称：客户原因、客服原因、客户产品需求、话术逻辑优化建议。
- 新增内部字段不导出。
- 现有 Excel 表头继续复用。
- 历史分析运行和人工复核结果不改写。

## 验收标准

- 新记录常规分析最多调用一次视觉模型和一次文本模型。
- 两个原因字段只能返回知识库中的标准名称，支持每类 1-2 个结果。
- 证据不足不会强行选择其他原因。
- 多个结果在导出单元格中换行。
- 话术建议默认不产生额外模型调用。
- 旧板块和热点话题现有行为不回归。
