# XLSX 资源与关系校验

> **文档状态：** 当前有效
> **适用对象：** 开发者、系统管理员
> **维护基准：** 2026-09-22 内网版本

上传安全检查现在会在交给 ExcelJS 之前校验：ZIP 目录路径、加密和压缩方式、条目数量、单条/总解压量、核心 XML、关系文件外部资源与路径存在性、每个条目的 CRC32，以及图片单图字节数、总图片字节数和像素数。

默认限制：单个内部文件 64 MiB、总解压 1 GiB、单图 32 MiB、图片总量 256 MiB、单图最多 10000×10000（总像素 1 亿）、条目最多 20000。图片支持 PNG、GIF、JPEG 尺寸头检查；其他图片格式会安全拒绝。限制可通过测试参数收紧，生产默认配置不从请求体覆盖。

关系文件只允许包内相对路径，拒绝 HTTP、HTTPS、file、data、UNC 和路径穿越；每个目标必须对应包内条目。核心结构缺失、截断、长度或 CRC 不符时返回 415；资源预算超限返回 413。上传写入过程中继续按 1 MiB 检查磁盘余量，检查失败删除临时文件。

2026-09-14 后续更新：已接入进程级共享磁盘预留器，上传及两种 Excel 导入在实际写入前申请预算，逐块核对并在落盘后抵扣，失败/断开后释放。校验声明解压量只是余量检查，不等同磁盘预分配。准确生命周期与跨进程边界见 [共享磁盘预留](shared-disk-reservations.md)。

历史验收记录（2026-09-13）：正常含截图工作簿通过；伪 ZIP、截断包、重复/穿越/加密/错误长度、缺失结构、图片像素和字节预算均有测试。当时全量 56 个测试文件、351 项测试通过，类型检查和构建通过；未调用付费模型。当前测试数量以 CI 为准。
