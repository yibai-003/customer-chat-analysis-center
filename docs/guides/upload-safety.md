# Excel 上传安全与资源限制

> **文档状态：** 当前有效
> **适用对象：** 开发者、系统管理员
> **维护基准：** 2026-09-22 内网版本

任务导入、任务预览、知识库预览和知识库确认导入共用 `security/upload-safety.ts`，不再读取整个上传文件来检查 4 字节签名。

## 检查顺序

1. multipart 请求开始前检查数据目录剩余空间。无法测量时返回 503，不静默放行。
2. 流式写入随机临时文件，每约 1 MB 重新检查剩余空间，并保留配置要求的空间及写入余量；磁盘不足停止写入并删除未完成临时文件。
3. 上传文件大小继续由 Multer 限制，默认 2048 MB；每次只接受一个文件，附加表单字段最多 20 个。
4. 少量字节读取 ZIP 文件头/尾，先限制中央目录体积和条目数，再解析目录；拒绝不完整、加密、分卷、ZIP64、重复或越界路径。
5. 必须存在 `[Content_Types].xml`、`_rels/.rels`、`xl/workbook.xml`、`xl/_rels/workbook.xml.rels`，核心 XML 必须语法有效，拒绝 DTD/实体定义。
6. 逐个流式读取内部文件，核对声明长度并检查实际展开字节，超限或超时中止；不把所有解压文件一次性放入内存。
7. 按声明解压总量检查磁盘余量后再移交业务解析。预览成功后正式上传仍独立校验；知识库确认也重新校验暂存文件。

## 当前上限

| 项目 | 上限 |
| --- | --- |
| ZIP 内部条目数 | 20,000 |
| 中央目录大小 | 16 MB |
| 单个展开文件 | 64 MB |
| 合计展开数据 | 1 GB |
| 单个核心 XML | 2 MB |
| 解压安全扫描时间 | 120 秒 |
| 最小可用空间 | MIN_FREE_DISK_MB，默认 512 MB |

超过内部资源限制时，即使上传体积小于 MAX_UPLOAD_MB 也会拒绝。大规模工作簿请拆分后导入。安全扫描会增加导入预检耗时。

## 错误状态

- 413：上传过大、内部条目/展开量超限或扫描超时。
- 415：扩展名/文件头错误、压缩包损坏、不支持的压缩格式或缺少核心结构。
- 507：磁盘空间不足。
- 503：无法读取磁盘可用空间。

## 验证边界

本阶段不等于完整 OOXML 规范验证：尚未逐条检查所有关系目标、图像像素上限、CRC，也未实现多导入任务之间的磁盘配额预留。剩余空间检查只能降低磁盘耗尽风险，不能保证外部程序同时写盘时空间永远充足。

当前 XML 业务解析仍会把单个工作表装入内存；64 MB 单条限制与 1 GB 扫描限制不是整个 Node 进程的内存上限。独立解析进程、图片解码限制和资源预约可在后续补充。

测试使用真实工作簿和目录故障注入，覆盖格式伪装、截断、加密标志、目录穿越、重复条目、尺寸不符、数量/展开限制、磁盘测量失败、写入中空间不足与临时文件清理。
