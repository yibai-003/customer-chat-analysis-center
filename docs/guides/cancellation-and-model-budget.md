# 取消链路与模型请求总预算

批量解析、单条解析和字段重试共享任务所有权与取消信号。取消会中止响应体读取和退避等待，停止后续字段、记录、知识匹配和热点沉淀；迟到响应按当前 token 拒绝写入。暂停允许当前记录完成，但不再领取下一条记录。单条技术异常会落为 failed/needs_review 并释放任务锁。

每个字段分析默认最多 6 次模型 HTTP 请求、5 分钟总时限，覆盖重试、JSON 降级和备用模型切换；达到预算后不会启动新的付费请求。用户强制关闭浏览器或进程时，服务无法收到取消信号，重启恢复会处理遗留运行。

2026-09-13 验收：新增本地 HTTP 取消、迟到响应、暂停、旧 token、热点队列及模型预算测试；全量 56 个测试文件、350 项测试，类型检查和构建通过，没有调用付费模型。现有数据库未做结构变更。
