# 服务端输入约束

> **文档状态：** 当前有效
> **适用对象：** 开发者
> **维护基准：** 2026-09-22 内网版本

本阶段把容易绕过前端的配置和导入参数放到服务端校验：板块名称与提示词、字段 Key/名称/提示词/依赖/选项/候选数量、模型名称、知识库列映射和分页参数均有类型、长度和数量边界。字段 Key 支持中文等 Unicode 字母，但禁止以数字开头及路径/控制字符。

校验失败在写库或开始导入前返回错误，不依赖浏览器表单；现有配置和中文板块保持兼容。2026-09-14 已补充字段枚举/布尔值、知识库列角色与条目值、输出 Schema、关联循环和模型 URL 校验，候选数统一为 5–30，详见 [配置与热点错误分类](../archive/configuration-and-hot-topic-validation.md)。

历史验收记录（2026-09-13）：当时 56 个测试文件、350 项测试通过，类型检查和构建通过。当前测试数量和构建状态以 CI 为准。
