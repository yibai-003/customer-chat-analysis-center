# 百炼免费模型池同步指南

## 目的

本指南用于在已登录阿里云百炼 CLI 的 Windows 管理主机上，把当前百炼账户的免费额度和模型目录同步到客服解析中心的模型池。同步只读取额度与目录，不调用模型推理；新模型应用后保持未入池，必须由管理员在项目内显式完成能力验证后再启用。

本流程只允许针对明确的局域网测试版地址执行。不要把测试地址、测试数据或本命令用于正式上线版本；正式版需要单独的备份、审批和验收流程。

## 实施顺序

1. 确认当前终端是 Windows PowerShell 7，工作目录是项目根目录，并确认目标是局域网测试版。不要使用正式版 URL、正式版数据目录或共享网络盘上的数据库。
2. 在主机上确认百炼 CLI 登录状态：

   ```powershell
   bl auth status
   ```

   如果登录已失效，先按百炼 CLI 的本机登录流程重新授权。不要把 CLI 配置目录、密码、Cookie 或 API Key 复制到项目、Docker 容器、环境变量或文档中。

3. 启动并确认局域网测试版正在运行，取得它的 HTTP(S) origin。回环 HTTP 或 HTTPS 均可；不要在命令中加入路径、查询参数或片段。例如测试端口为 `4310` 时：

   ```powershell
   npm run pool:sync:bailian -- -BaseUrl http://127.0.0.1:4310
   ```

   多个百炼服务商时，可追加服务商 ID：

   ```powershell
   npm run pool:sync:bailian -- -BaseUrl http://127.0.0.1:4310 -ProviderId <enabled-provider-id>
   ```

4. 脚本在内存中读取 CLI 的免费额度和精确模型详情，随后提示登录项目管理端。选择与当前 CLI 账户属于同一个百炼账户的、已启用的项目服务商。脚本会再次要求输入 `SAME BAILIAN ACCOUNT`；无法确认时退出，不提交快照。
5. 检查预览中的新增、更新、停用、保留人工状态和排除原因。普通变更只有在输入 `APPLY BAILIAN FREE POOL` 后才会应用。若候选为零且将停用全部受管免费模型，还必须输入 `STOP ALL MANAGED FREE MODELS`；不输入则不会写入数据库。
6. 应用成功后回到项目模型池页面刷新。新成员默认未加入路由，逐个选择需要的模型，使用现有“验证已选”动作完成能力验证，再由管理员显式启用。视觉验证会实际调用模型，可能消耗百炼免费额度。

## 验收

- 脚本先完成 CLI 输出、额度范围、有效期、目录版本和能力字段校验；任何不完整或超限数据都不会发送预览请求。
- 预览和应用均显示标准错误信息，不显示密码、Cookie、API Key、完整账户标识或 CLI 原始 JSON。
- 应用后检查模型池：新成员存在但未验证前不参与路由；过期、耗尽、下线或不满足能力标准的受管成员被停用但保留行和历史；手动剔除、冷却、失败诊断、能力记录和使用事件未被同步重置。
- 两个付费 purpose-default 保底模型、服务商凭据、付费预算和分析历史保持不变，并在列表/路由排序中位于免费成员之后。
- 运行完成后保留脱敏的变更数量和时间即可，不要保存完整额度清单或命令行交互转录。

## 回退与失败处理

- 预览过期、登录失效、服务商被停用或池状态发生变化时，应用会拒绝写入；重新确认目标测试版后重新执行预览即可。
- 在输入确认短语前退出不会产生模型池变更。应用事务失败时服务端整体回滚，不要手工删除模型行或使用 SQL 绕过服务。
- 若需要回到应用前的状态，先停止测试版写入，使用项目既有备份/恢复指南针对同一测试数据目录执行恢复，并保留失败时间、错误摘要和备份名称。不要把备份恢复到正式版或覆盖正在运行的数据库。
- CLI 查询失败、额度记录缺失、目录详情重复或模型输出超过限制时，修复 CLI 登录/网络问题后重新运行；不要把原始响应粘贴到 Issue、日志或聊天中。

## 安全边界

- 采集器只允许白名单只读 CLI 命令，不执行聊天推理、写额度或云端配置开关操作。
- 项目登录密码和会话 Cookie 仅在当前 PowerShell 进程内存中存在；脚本结束或失败时会清理并尝试登出。
- 不要通过浏览器直接触发主机 CLI，也不要在容器中挂载百炼 CLI 登录目录。需要自动化代理时必须另行设计授权边界。
