# 历史归档说明

本目录保存已经完成的实施计划、进度账本、一次性验收记录、修复报告和历史决策依据。
这些文件用于追溯，不是当前操作手册。

## 使用原则

- 当前部署、运维和故障处理以 [`../guides/`](../guides/) 为准。
- 当前架构约束以 [`../adr/`](../adr/) 和
  [项目开发规范](../project-structure-and-development-guidelines.md) 为准。
- 归档中的提交号、镜像、测试数量、IP、端口和状态只代表记录日期当时的情况。
- 归档文件之间允许保留历史术语和旧状态，不应据此覆盖当前运行配置。

## 内容分类

- `lan-*`：局域网部署、业务流程和发布验收记录。
- `architecture-*`：已完成的架构治理计划与进度。
- `operational-efficiency-*`：已完成或取消的模型池、批量操作和效能计划。
- `task-*`：一次性开发任务报告。
- `*-remediation-*`、`fix-*`：定向修复和稳定性治理记录。

需要寻找当前文档时，请返回[文档中心](../README.md)。
