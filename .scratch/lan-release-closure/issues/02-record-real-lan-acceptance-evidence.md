# 02: 回填真实局域网业务验收证据

**What to build:** 将已经完成的跨电脑真实数据导入、分析和导出结果，整理为脱敏、可追溯的正式验收记录，并同步更新局域网发布工单的真实状态；未实际验证的项目继续保持未完成。

**Blocked by:** 01: 收敛正式模型池基线

**Status:** ready-for-agent

- [ ] 记录真实验收的主机入口、工作站标识、执行时间、运行镜像、提交或版本信息和正式模型供应商名称，不记录 API Key。
- [ ] 记录真实数据样本的脱敏说明、文件哈希、任务数量、记录数量、解析数量、成功数量和失败数量。
- [ ] 记录跨电脑导入、真实模型解析、结果查看和导出均已通过，并附脱敏截图、接口摘要或可复查的证据文件。
- [ ] 明确区分“已通过”“未执行”“不适用”“失败”；不得用桩模型、同机演练或代码存在替代真实证据。
- [ ] 若已实际执行，补充审核人员复核、只读人员权限、导出内容和越权请求的证据；未执行则保留待办。
- [ ] 若已实际执行，补充主机重启、备份创建、独立恢复和数据持久化证据；未执行则保留待办。
- [ ] 将 Issue 07、Issue 11、Issue 12 的状态和验收表更新为与证据一致，删除已经过期的“待提交”或“机器等价”表述。
- [ ] 检查验收材料不包含密码、Cookie、API Key、加密密钥、完整业务 Excel、完整图片或敏感路径。
- [ ] 在文档中保留遗留风险：HTTP 局域网入口、单机 SQLite、主机资源瓶颈和正式 HTTPS 尚未完成。
