# 01: 收敛正式模型池基线

**What to build:** 管理员可以在运行主机上明确区分正式供应商、正式文本模型、正式视觉模型和测试/桩模型；正式路由只使用已验证的正式模型，测试模型不会被真实局域网任务误调用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 盘点当前模型供应商、模型配置、默认模型、池启用状态、能力检测状态和最近使用记录，输出脱敏基线清单。
- [ ] 确认正式供应商凭据已由管理员保存在主机，工作站和验收脚本不携带 API Key。
- [ ] 至少配置并验证一个正式文本模型和一个正式视觉模型；两者均可通过连通性检测、能力检测和 `/api/ready` 就绪检查。
- [ ] 将测试供应商、桩模型和临时验收模型停用、移出路由池或按历史引用约束安全删除；不得直接修改数据库文件。
- [ ] 设置正式文本默认模型和正式视觉默认模型，确认解析路由不会落到测试模型。
- [ ] 变更前创建可验证备份；变更后保留模型池变更、验证、默认模型设置和失败结果的审计记录。
- [ ] 从另一台局域网电脑使用正式模型完成至少一条真实记录解析，确认输入、输出、模型使用事件和错误信息均正常。
- [ ] 若正式供应商或正式模型尚未满足条件，保留明确阻塞说明，不得把桩模型状态标记为正式通过。
- [ ] 更新模型池运行说明，记录正式基线、备用模型策略、测试模型隔离规则和回退步骤。
