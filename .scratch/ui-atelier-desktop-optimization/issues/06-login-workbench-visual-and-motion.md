# 06: 登录工作台分屏与动态分析画布优化

**What to build:** 在保留现有账号密码认证、管理员初始化提示和局域网访问约束的前提下，将登录页升级为桌面优先的分屏工作台入口。登录表单保持清晰、稳定和高可用，右侧使用轻量动态分析画布强化数据中台属性，并以少量植物标本、水彩纸片和胶带元素延续 ATELIER 品牌风格。

**Blocked by:** 01: ATELIER 桌面端 UI 实现

**Related:** 04: 分析工作台组件层级与视觉降噪；05: 响应式记录详情工作区

**Status:** done (2026-09-22) — 登录工作台视觉、动态画布、离线素材、真实登录和多分辨率验收完成

## Problem

1. 当前登录页使用单张居中卡片，与登录后的三栏分析工作台在空间结构和信息密度上差异较大。
2. 植物元素仅出现在品牌标识内部，能够提供品牌识别，但没有体现“客服数据分析工作台”的产品属性。
3. 登录页缺少适合桌面端的视觉重心和进入工作台前的状态感知。
4. 参考 UI 使用 Tailwind、shadcn、路径别名和多项外部依赖，而当前项目使用 Vite、React、TypeScript 和原生 CSS，直接复制会引入第二套样式系统。
5. 参考 UI 包含邮箱、GitHub 登录、注册和找回密码等当前系统不存在的入口，不能直接合并。

## Design Direction

- 整体视觉权重保持约 `85%` 数据工作台、`15%` 水彩手账风格；该比例描述视觉语言，不要求按页面面积机械划分。
- `1100px` 及以上采用双栏布局：
  - 左侧约 `44%-48%`：品牌、账号密码表单、错误提示、管理员初始化提示和局域网使用说明。
  - 右侧约 `52%-56%`：动态分析画布。
- 动态分析画布使用工作台语汇：
  - 低对比度网格和刻度。
  - 字段节点、连接线、扫描轨迹和状态指示。
  - 少量任务状态或字段标签，但不展示虚假业务统计。
- 水彩手账语汇限制为：
  - 一组本地植物标本素材。
  - 一至两层低透明度纸片或水彩晕染。
  - 少量胶带或纸张边缘质感。
- 不使用高饱和霓虹渐变、玻璃拟态、大面积纯装饰动画或营销页式文案。
- 所有持续动画只使用 `transform` 和 `opacity`，不得阻塞输入、提交或错误反馈。

## Technical Decision

- 继续使用现有 React、TypeScript 和原生 CSS。
- 不引入 Tailwind CSS、shadcn/ui、Radix、`class-variance-authority`、`@aliimam/logos` 或外部动画库。
- 不创建 `src/client/components/ui` 作为并行组件体系。
- 参考组件中的 Gradient Mesh 只作为动效方向，不复制其依赖和实现。
- 动态画布优先使用 CSS、语义化 HTML 和现有本地位图素材；只有 CSS 无法满足稳定性时才考虑轻量 Canvas。
- 所有品牌和装饰图片必须来自项目本地资源，局域网断网时页面仍完整可用。

## Scope

- 调整 `SignIn` 的页面结构，但保留以下业务逻辑：
  - `fetchAuthStatus()`。
  - `loginRequest()`。
  - `setSession()`。
  - 账号和密码的自动填充语义。
  - 登录忙碌态和服务端错误信息。
  - `bootstrap:admin` 管理员初始化提示。
- 新增独立、无业务状态依赖的登录动态画布组件。
- 为登录页增加桌面双栏、中等尺寸单栏和窄屏布局。
- 优化账号输入框、密码输入框、登录按钮、错误提示和初始化提示的视觉层级。
- 保留“仅限内部局域网已授权用户使用”说明。
- 动态画布设置 `aria-hidden="true"`，不进入键盘焦点顺序。
- 支持 `prefers-reduced-motion: reduce`，关闭扫描、漂移和循环位移动画。

## Out Of Scope

- 不修改认证 API、Cookie、Session、密码策略、账号管理和权限能力。
- 不增加邮箱登录、GitHub 登录、注册、找回密码或第三方认证。
- 不改变首次管理员创建方式。
- 不修改登录后的工作台布局和业务组件。
- 不引入新的 CSS 框架、组件库、图标库、动画库或远程字体。
- 不使用外部 CDN 图片、在线纹理或依赖公网加载的资源。
- 不处理线上版本的 OAuth、验证码、多因素认证或单点登录。

## Completion Gate

只有同时满足以下条件，才能将工单状态改为 `done`：

1. 全部验收标准勾选完成。
2. 登录专项测试、类型检查、Lint、生产构建和全量测试通过。
3. 四个目标桌面视口没有横向滚动、裁切、重叠或关键内容不可达。
4. `prefers-reduced-motion` 和键盘登录完成真实浏览器验证。
5. 页面在无公网条件下资源完整，真实管理员登录、退出和重新登录均成功。
6. 最终截图和验证结果归档到验收文档。

## Implementation Result

- 登录页已重构为桌面双栏工作台入口，`1099px` 及以下自动收敛为单栏表单。
- 新增 `LoginAnalysisCanvas`，使用四步基础流程节点表达导入到导出的工作流。
- 移除登录前解析预览卡片、扫描线和流程说明卡，避免展示与当前会话无关的业务状态。
- 右侧仅保留一组现有本地植物装饰，并使用低幅度 `transform` 漂移动画。
- 画布整体设置 `aria-hidden="true"`，内部没有链接、按钮、输入框或 `tabindex`。
- 登录表单新增 `aria-busy`，请求期间禁用提交按钮并阻止重复提交。
- 四个目标视口均无横向滚动、文字裁切或组件重叠；`1024x768` 单栏模式无纵向溢出。
- 登录相关源码不包含外部 URL，本地植物图片在真实局域网页面中全部加载成功。
- 历史验收密码已失效，真实错误态已完成验证；随后使用当前管理员凭据完成成功登录、退出、重新登录和断公网登录验收。
