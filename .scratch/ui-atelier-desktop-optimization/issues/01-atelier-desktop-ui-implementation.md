# 01: ATELIER 桌面端 UI 实现

**What to build:** 将已确认的 ATELIER 视觉方向落地到客服解析中心的登录页、工作台外壳、任务与记录列表、详情区域、详情抽屉和通用弹窗，保持现有业务流程、权限、接口和数据模型不变。

**Blocked by:** None

**Status:** done (2026-09-18)

- [x] 登录页、工作台、弹窗和状态标签使用统一的暖纸色、苔绿色、墨线和硬阴影视觉语言。
- [x] 主题规则挂载在明确的主题根节点下，没有把交付目录中的整份全局 CSS 直接叠加到生产样式。
- [x] `1366px` 及以上宽度保留侧栏、主内容和详情三栏；`1024px-1279px` 下详情改为右侧抽屉。
- [x] 详情抽屉支持打开、关闭、点击遮罩关闭、Escape 关闭、焦点进入和焦点返回原记录触发按钮。
- [x] 侧栏支持折叠，折叠后仍保留任务状态和关键导航入口。
- [x] 记录列表保留单选、多选、批量解析、状态筛选和详情查看行为；长文本不会破坏主要网格结构。
- [x] 弹窗关闭按钮、登录按钮、业务按钮和状态元素具备明确的语义、焦点和禁用状态。
- [x] `prefers-reduced-motion` 下不依赖动效才能完成操作。
- [x] 客户端新增的详情抽屉行为测试通过，既有登录、权限、知识库、导入导出和记录选择测试未回归。

**实现结果：**

- 新增 `src/client/atelier-theme.css` 作为作用域主题层。
- 更新 `App.tsx`，补充侧栏折叠、详情抽屉、Escape 和焦点恢复。
- 更新 `index.html`、`main.tsx` 和 `Modal.tsx`，统一主题挂载与弹窗语义。
- 新增详情抽屉回归测试。
- `npm run typecheck`、`npm run build` 和全量测试通过；全量结果为 89 个测试文件、673 个测试通过。
