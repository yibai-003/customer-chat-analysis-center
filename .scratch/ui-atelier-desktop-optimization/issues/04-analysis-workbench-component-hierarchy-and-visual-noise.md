# 04: 分析工作台组件层级与视觉降噪

**What to build:** 在保留 ATELIER 暖纸色、苔绿色、方形组件和品牌标识的前提下，将当前偏重的编辑部装饰语言收敛为适合内部分析中台长期使用的工作台组件系统，突出数据、任务状态和高频操作。

**Blocked by:** 01: ATELIER 桌面端 UI 实现

**Related:** 02: 真实局域网多分辨率验收；03: 工作台顶部操作层级与响应式菜单优化

**Status:** done (2026-09-22) — 代码、自动化、四尺寸真实任务验收和完成态截图归档完成

## Problem

1. 按钮、筛选器、任务项和菜单普遍使用粗边框与硬阴影，主次操作视觉权重接近。
2. 植物插画、纸张纹理和装饰字体在数据工作区中的存在感偏高。
3. 多处辅助文字低于适合中文桌面工作台长期阅读的字号。
4. 已完成任务仍展示完整的双进度条，占用记录列表上方空间。
5. 深色列表表头和大量墨线同时出现，连续浏览记录时视觉负担偏重。

## Scope

- 顶部操作使用明确的三级层级：
  - 主操作：导入 Excel。
  - 次操作：导出结果。
  - 三级操作：刷新进度。
- 批量解析继续作为当前任务区域的主操作，不改变业务逻辑。
- 已完成任务将双进度条折叠为单行摘要；处理中任务继续显示完整进度。
- 降低普通按钮、用户入口、筛选器、任务项和列表区域的阴影与粗边框使用。
- 降低工作区植物插画和纸张点阵纹理的对比度，但保留品牌识别。
- 提高菜单、侧栏状态、记录状态、辅助字段和详情标签的最低可读字号。
- 将记录表头调整为低噪声数据表头，同时保留清晰的列边界和扫描层级。

## Out Of Scope

- 不修改服务端 API、数据库、权限和任务状态定义。
- 不修改记录详情抽屉的响应式布局；该内容属于后续工单 05。
- 不改变导入、解析、导出、复核和配置流程。
- 不引入新的组件库、图标库或字体依赖。
- 不移除 ATELIER 品牌色、方形组件和植物标本元素。
