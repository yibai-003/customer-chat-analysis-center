# 06：单板块导出与截图行多问题聚合

**Status:** ready-for-agent  
**Priority:** high  
**Risk:** high  

## What to build

收敛项目导出契约：一次导出只接收一个任务，并由任务绑定的板块和配置版本决定目标字段、表头、顺序、格式和目标行。

保留原工作簿、工作表、行、样式、图片、公式和无关单元格。目标列存在时原位回填，不存在时追加到工作表末尾。平台和会话 ID 使用版本配置的目标表头；接待流程质检初始映射为 `平台 (platform_name)` 和 `会话ID (conversation_id)`。

接待质检只修改截图行，不使用预留行，也不新增问题行。内部结构化问题数组只在导出层序列化：

- `问题`、`维度`、`扣分`按同一索引顺序使用英文逗号连接。
- `合计扣分`填写扣分总和。
- `是否D级`按会话聚合。
- `证据说明`、`判定理由`和`优化建议`按问题顺序编号换行。
- `聊天原文`只保留问题相关片段，去重后合并且不逐问题编号。

为避免逗号协议歧义，配置发布时禁止问题名称和维度名称包含英文逗号。导出前校验结构化数组数量对齐和 Excel 单元格长度，超限时阻止导出并报告行号，禁止静默截断。

## Blocked by

- 03：全板块会话 ID 幂等派发
- 05：接待质检两阶段分析与版本化规则派生

## Acceptance criteria

- [ ] 导出 API 不再默认或允许本流程一次导出多个板块。
- [ ] 任务绑定板块和版本是导出字段、表头和格式的唯一配置来源。
- [ ] 原工作簿的工作表、行、样式、图片、公式和无关单元格保持不变。
- [ ] 目标列存在时原位回填，不存在时追加到工作表末尾。
- [ ] 平台和会话 ID 按版本配置的目标表头输出。
- [ ] 接待质检只修改截图行，无图片预留行完全不变。
- [ ] 不为多个问题增加新行。
- [ ] `问题`、`维度`、`扣分`使用英文逗号并保持相同顺序。
- [ ] 三个多值数组长度不一致时阻止导出并报告记录和字段。
- [ ] 配置发布时拒绝包含英文逗号的问题名称和维度名称。
- [ ] `合计扣分`写所有问题扣分总和。
- [ ] `是否D级`在任一 D 级问题时为“是”，有问题但无 D 级时为“否”，无问题时为空。
- [ ] `证据说明`、`判定理由`和`优化建议`按 `1.`、`2.` 编号换行并与问题顺序对齐。
- [ ] `聊天原文`仅包含问题相关片段，去重后合并且不逐问题编号。
- [ ] 无问题且信息充分时输出 A、0、待复核“否”，问题详情和建议为空。
- [ ] 单元格内容超过 Excel 限制时阻止导出并报告工作表、行号和字段，不静默截断。
- [ ] 导出后重新读取真实工作簿，断言值、换行、图片锚点、行数、样式和公式符合契约。
