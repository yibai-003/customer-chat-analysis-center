# 04：接待质检新模板导入契约

**Status:** ready-for-agent  
**Priority:** high  
**Risk:** high  

## What to build

实现接待流程质检新模板的导入识别和结果区状态校验。

只为带聊天截图的原始行创建分析记录。截图后的无图片预留行不参与分析、不补平台、不生成会话 ID，也不填写结果。

为接待质检版本明确配置“结果区字段集合”和“完整历史结果必填集合”，禁止使用“多数单元格已填写”之类的模糊判断：

- 结果区全部为空：创建待分析记录。
- 完整历史结果满足配置定义：整行跳过，不覆盖，也不作为模型证据。
- 结果区部分填写或字段组合不合法：整份导入失败，并列出冲突行和缺失/多余字段。

导入过程中保留原工作簿、工作表、行号、样式、图片和无关单元格，供后续原位导出使用。

## Blocked by

- 02：平台字典与导入任务三项绑定

## Acceptance criteria

- [ ] 导入任务自动绑定接待质检当前启用的已发布版本。
- [ ] 只有带受支持图片锚点的原始行创建分析记录。
- [ ] 无图片预留行不创建记录、不补平台、不生成 ID、不填写结果。
- [ ] 结果区字段和完整历史结果必填字段由版本配置明确给出。
- [ ] 结果区全部为空时创建待分析记录。
- [ ] 完整历史结果行被跳过且不被覆盖。
- [ ] 已有结果不进入视觉模型或质检模型上下文。
- [ ] 结果区部分填写或字段组合非法时整份导入失败。
- [ ] 错误报告包含工作表、行号、冲突字段和原因。
- [ ] 原工作簿的图片、样式、行位置和无关单元格被完整保留。
- [ ] 使用真实 XLSX 和 WPS 产生的样本验证图片锚点识别。
- [ ] Service 测试覆盖空结果、完整结果、部分结果、多工作表和无图片预留行。
