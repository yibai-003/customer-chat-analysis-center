# 02：平台字典与导入任务三项绑定

**Status:** ready-for-agent  
**Priority:** high  
**Risk:** medium-high  

## What to build

建立平台字典，并将一次导入任务固定绑定为一个分析板块、一个平台和该板块当前启用的已发布配置版本。

导入人员选择板块和启用平台后，系统展示将要绑定的版本号和版本说明。导入人员不能为单次任务临时选择历史版本。任务创建后，板块、平台和版本均不可修改。

源 Excel 可以没有平台列。若平台列存在且单元格为空，以任务平台为准；若存在任何非空值与任务平台冲突，整份导入失败并列出全部冲突行。

历史任务不自动猜测平台。管理员可以对缺少平台的历史任务补录一次；补录后锁定，并写入审计记录。

## Blocked by

- 01：全板块配置版本生命周期与 V1 迁移

## Acceptance criteria

- [ ] 管理员可以新增、改名、停用和恢复平台。
- [ ] 平台代码全局唯一。
- [ ] 平台尚未被任务使用时允许修改代码。
- [ ] 平台一旦被任务使用，代码不可修改且平台不可删除。
- [ ] 停用平台不能用于新任务，但历史任务仍能正常查看和导出。
- [ ] 导入界面要求且只允许选择一个板块和一个启用平台。
- [ ] 系统自动展示并绑定该板块当前启用版本。
- [ ] 创建任务后，板块、平台和版本不可修改。
- [ ] 源文件没有平台列或平台值为空时可以导入。
- [ ] 任一非空平台值冲突时整份导入失败，并列出全部冲突行。
- [ ] 历史任务不根据文件名、店铺、用户或 Excel 内容推断平台。
- [ ] 管理员可以为历史任务补录一次平台，保存后不可修改。
- [ ] 平台维护、任务绑定和历史补录写入审计记录。
- [ ] Service、HTTP 和 UI 测试覆盖缺列、空值、冲突、停用平台和不可变绑定。
