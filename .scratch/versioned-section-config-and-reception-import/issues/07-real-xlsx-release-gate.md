# 07：真实 XLSX 端到端验收与版本回退发布门禁

**Status:** ready-for-agent  
**Priority:** high  
**Risk:** medium-high  

## What to build

使用脱敏真实接待质检文件完成从导入到导出的全链路验收，并把该验收作为功能发布门禁。

验收文件需要覆盖：源文件无平台列、无问题、单问题、多问题、D 级、待复核、缺少可靠会话时间、已有完整结果、部分结果冲突和无图片预留行。

验收还需要证明配置版本切换不会影响历史任务：用新版本导入第一个任务，重新启用历史版本后导入第二个任务，再重试第一个任务，确认两个任务分别继续使用各自绑定版本。

导出文件分别使用 Excel 和 WPS 打开，并通过程序重新读取，检查图片、样式、公式、行数、预留行和所有目标字段。

## Blocked by

- 06：单板块导出与截图行多问题聚合

## Acceptance criteria

- [ ] 脱敏真实文件完成导入、平台选择、版本绑定、分析、ID 派发和导出。
- [ ] 无平台列的文件使用任务平台正确输出。
- [ ] 无问题、单问题、多问题、D 级和待复核场景均符合规格。
- [ ] 已完成和待复核记录各自只生成一次会话 ID。
- [ ] 完整历史结果行被跳过，部分结果行使整份导入失败并输出行级错误。
- [ ] 无图片预留行在导出前后完全不变。
- [ ] 多问题的“问题、维度、扣分”数量和顺序严格对齐。
- [ ] 激活历史版本后，新任务使用历史版本，旧任务继续使用原绑定版本。
- [ ] 旧任务重试不会改变配置版本、知识快照、规则结果或会话 ID。
- [ ] Excel 和 WPS 均能正常打开导出文件。
- [ ] 程序重新读取后，图片、样式、公式、工作表、行数和目标单元格均符合预期。
- [ ] 自动化测试、类型检查和生产构建全部通过。
- [ ] 验收记录包含样本路径、平台、版本、任务、会话 ID 示例、导出文件和验证结果。
- [ ] 任一发布门禁失败时不得标记功能完成或进入正式发布。
