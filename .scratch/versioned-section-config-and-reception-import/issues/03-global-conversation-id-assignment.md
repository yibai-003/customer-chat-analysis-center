# 03：全板块会话 ID 幂等派发

**Status:** ready-for-agent  
**Priority:** high  
**Risk:** medium-high  

## What to build

把会话 ID 建成所有分析板块共享的系统业务标识，并接入单条记录的状态转换。

记录首次进入“已完成”或“待复核”时，使用任务平台代码、Asia/Shanghai 当天日期和六位大写英文字母或数字随机码生成会话 ID。派发和状态转换必须处于同一个事务或等价的原子幂等单元中。

数据库使用全局唯一约束兜底。随机码碰撞时重新生成并在有界次数内重试；超过上限时返回明确错误，不允许写入重复 ID。

已派发 ID 在任务重试、重新分析、重新导出、版本切换以及“已完成/待复核”之间往返时保持不变。

## Blocked by

- 02：平台字典与导入任务三项绑定

## Acceptance criteria

- [ ] 所有板块的记录首次进入已完成或待复核时自动获得会话 ID。
- [ ] 其他状态不生成会话 ID。
- [ ] ID 格式为平台代码 + `yyyyMMdd` + 六位大写英文字母或数字。
- [ ] 日期使用 Asia/Shanghai 的实际派发日期。
- [ ] 会话 ID 在数据库中全局唯一。
- [ ] 人工构造随机码碰撞时会重新生成。
- [ ] 达到碰撞重试上限时返回明确错误且不提交状态转换。
- [ ] 并发状态转换不会为同一记录生成两个 ID。
- [ ] 重试、重新分析、重新导出和状态往返不会改变已派发 ID。
- [ ] 切换板块当前启用版本不会改变历史记录的会话 ID。
- [ ] 缺少任务平台的历史任务不能派发 ID，并返回需要补录平台的明确状态。
- [ ] 单元和数据库集成测试覆盖格式、时区、碰撞、并发、幂等和永久复用。
